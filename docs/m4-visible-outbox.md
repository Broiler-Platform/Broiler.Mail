# M4 — Visible manual outbox and retained submission outcomes

Implemented 2026-11-03. Five items:

1. **Live bounded projection.** Outbox combines the current composer with the existing saved-draft library, scoped to the selected stable account ID. The existing maximum is one active plus 20 parked records across the profile, inside the existing 4 MiB draft-file bound. There is no new persisted queue/schema or network read. The current row reflects live edits/outcomes; the storage-status line separately identifies unsaved changes/failures. An unreadable draft store reports outbox unavailable instead of an empty successful result.
2. **Independent outcome filters.** All retained, unsent/rejected, in progress, needs review and SMTP accepted filters preserve separate SMTP and Sent-copy states. Saved interrupted Sending/Pending records project as Unknown without rewriting them merely to inspect them. A live send or Sent-copy attempt remains in progress; failed/unknown Sent copying never turns SMTP acceptance into an unsent message. Browsing/filtering remains possible while work runs; handoff is disabled. Account changes reset scope/filter/selection and clear previous details.
3. **Copyable attributed details.** Explicit row selection shows account/ID, pinned From/name, draft ID/location, assigned UTC submission date, bounded subject/raw recipient edits and independent outcome guidance. Body text is omitted; list labels sanitize controls without splitting surrogate pairs. Raw recipient display is capped at 4,096 UTF-16 characters per field and is not proof of delivery. Accepted is not a delivery guarantee; unknown acceptance requires provider/recipient review; failed/unknown Sent copies never invite resending.
4. **Guarded Compose handoff.** Open selected in Compose (save current first) flushes the active draft and uses the existing revision-checked atomic library activation/swap for a parked record. Preserve IDs, pinned sender, raw edits, threading and submission/Sent-copy states; any previous active draft is retained. No submission, Sent-copy retry, removal or scheduling occurs. Accepted/unknown outcomes stay protected by the Composer. Failed save/account/storage/busy guards prevent handoff, and closing/reopening a modal while a local save completes cannot trigger late navigation into Compose.
5. **Visible shell access and acceptance.** Mail → Outbox and Ctrl+5 open the bounded keyboard-operable outbox dialog; Escape/Close return normally. Tests cover account filters, interruption projections with zero writes, independent live outcomes, copyable details, raw-draft preservation, unknown/accepted reopen protection, failed saves/unreadable state, 100%/200% text, live-send browsing and closed-dialog races. Published NativeAOT/framework-dependent smoke covers local outbox inspection, retained-record handoff, restart and backup/restore/cache cleanup, with a transport that must never be invoked. General shell smoke now includes Outbox.

## Scope

This is a visible **manual outbox of retained local records**, not a background send queue or complete sent history. Records disappear when explicitly discarded/removed through the existing composer/library controls. Saving/parking does not schedule sending, opening does not resend, and viewing accepted records does not query a server. Switching accounts while the dialog is open follows the existing modal restrictions; close it to choose another account. Disabled accounts can inspect local records; normal send authorization still applies in Compose.

Existing drafts and submission journals provide persistence and recovery; there is no migration or new automatic write when just filtering/inspecting. The existing saved-recipient prefix picker supplies explicit recipient completion. This completes M4's multiple-drafts/explicit completion/visible manual outbox item; background dispatch/scheduling, general attachments, `.eml` import, broader provider/crash/power-loss/accessibility/other-target acceptance and renderer containment remain open.
